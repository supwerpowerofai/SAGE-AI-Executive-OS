# SAGE Development Roadmap

This roadmap distinguishes planned work from verified implementation.

## v0.1 — Local execution core

- [x] SQLite-backed project and task model
- [x] CLI commands for projects and tasks
- [x] Priority and status handling
- [x] Dashboard counts
- [x] Unit tests for core workflows
- [ ] Run tests in a clean environment and record the result

## v0.2 — Usability

- [ ] Interactive dashboard
- [ ] Due-date filtering and overdue view
- [ ] Edit and archive workflows
- [ ] Export and backup

## v0.3 — Executive review

- [ ] Daily review record
- [ ] Weekly review summary
- [ ] Blocker and dependency tracking
- [ ] Decision journal

## v0.4 — Optional AI assistance

- [ ] Provider-neutral model adapter
- [ ] Context preview before external transmission
- [ ] AI-generated plans clearly labeled as suggestions
- [ ] Human approval for consequential actions

## Release discipline

A checkbox is marked complete only after code exists and its behavior has been verified. Planned integrations must not be described as active capabilities.
