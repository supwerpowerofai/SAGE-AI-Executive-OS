# 21-Project AI Automation Portfolio

**Portfolio owner:** Aryan Saroha  
**Positioning:** AI Automation & Growth Systems  
**Standard:** Every project must contain working code, setup instructions, tests, documented limitations, and verifiable evidence before it is marked complete.

This is a delivery roadmap, not a claim that all projects are already built. Projects are delivered sequentially and individually verified. Avoid creating empty repositories merely to increase repository count.

## Portfolio tracks

### 1. Executive and business operations
1. **SAGE AI Executive OS** — local-first project, task, priority, decision and review management.
2. **OPERONIX AI Follow-up Engine** — lead lifecycle, follow-up scheduling, consent-aware message templates and provider adapters.
3. **Lead Follow-up CRM** — evolve the existing browser prototype into a tested, documented lead management application.
4. **Business KPI Dashboard** — import business metrics and display transparent operational summaries.
5. **Quotation and Invoice Generator** — create validated quotations and invoices with PDF export.

### 2. Practical AI applications
6. **AI Research Brief Generator** — turn supplied sources and notes into structured, cited research briefs.
7. **Document Q&A Workspace** — search a user's local documents with source references and explicit uncertainty.
8. **Meeting-to-Actions Assistant** — convert supplied meeting notes or transcripts into reviewable tasks and decisions.
9. **Customer Support Knowledge Assistant** — answer questions from a curated knowledge base and show supporting passages.
10. **Prompt Evaluation Lab** — version prompts, run repeatable test cases and compare outputs against explicit criteria.

### 3. Automation engineering
11. **Webhook Inspector and Replay Tool** — receive, inspect, validate and safely replay sample webhook payloads.
12. **API Integration Starter Kit** — reusable API client patterns, retries, timeouts, pagination and structured errors.
13. **CSV Data Quality Toolkit** — profile, validate, clean and report on tabular business data.
14. **n8n Workflow Library** — documented importable workflows with sample payloads, setup steps and failure handling.
15. **Make Automation Blueprint Pack** — documented scenarios, mapping examples and test fixtures.

### 4. Growth and marketing systems
16. **Content Repurposing Workbench** — transform supplied long-form content into editable channel-specific drafts.
17. **Campaign UTM Builder and Analyzer** — create consistent tracking links and summarize imported campaign data.
18. **Landing Page Lead Capture Demo** — validated form capture, consent notice, spam controls and exportable leads.

### 5. Commercial and commerce tools
19. **E-commerce Margin Calculator** — calculate contribution margin with editable costs, fees, taxes and assumptions.
20. **Product Catalog Enrichment Tool** — normalize product data, flag missing attributes and generate reviewable descriptions.
21. **Sales Pipeline Forecasting Tool** — forecast pipeline using explicit stage probabilities and editable assumptions.

## Delivery sequence

Build in this order unless dependencies or evidence justify a change:

1. Audit and complete SAGE's first runnable milestone.
2. Run its tests locally and in GitHub Actions; fix failures before proceeding.
3. Upgrade the existing Lead Follow-up CRM without overstating integrations.
4. Build OPERONIX AI on reusable, testable lead-follow-up foundations.
5. Deliver projects 4–21 in small, independently demonstrable milestones.

## Definition of done

A project is **complete** only when all applicable items are verified:

- [ ] Source code is committed to GitHub.
- [ ] A fresh setup can follow the documented instructions.
- [ ] Core behavior has automated tests.
- [ ] Tests have actually been run and passed.
- [ ] Inputs, outputs, errors and security/privacy boundaries are documented.
- [ ] A demo, screenshot or reproducible example is available where useful.
- [ ] Known limitations are stated honestly.
- [ ] README status and evidence links match the implementation.

## Status legend

- **Planned:** not implemented.
- **In progress:** implementation underway; not yet verified complete.
- **Implemented:** code exists; verification may still be pending.
- **Verified:** setup and relevant tests have been run successfully; evidence is recorded.

Do not mark a project verified based only on file publication or the existence of a CI workflow.
